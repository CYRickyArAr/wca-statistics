# WCA 非官方连续平均统计

从 WCA 的正式比赛**逐次成绩**计算官网没有的连续平均：**Ao5、Ao12、Ao25、Ao50、Ao100**。默认包含十五位选手，可以继续自行添加选手，支持直接部署到 GitHub Pages。

不再以官方 PB、世界排名等作为主页内容。

## 启动

双击 **`启动WCA统计.bat`**，打开 **http://localhost:5288**。

或者在此目录运行：

```sh
npm start
```

需要 Node.js 22+，无第三方依赖，无需 `npm install`。保持启动窗口打开，按 `Ctrl+C` 停止。只在本机监听，不影响其他端口的应用。

若服务已经启动，修改网页后刷新页面即可，不需要重新获取成绩。若缓存了旧网页，可用 `Ctrl+F5`。此前在 **5288** 添加的选手与缓存继续保留。

端口占用时，可在 PowerShell 中执行 `$env:PORT=5289; npm start`。不同端口、浏览器、`localhost` 和 `127.0.0.1` 的浏览器存储彼此独立。

## 部署到 GitHub Pages

1. 在 GitHub 新建仓库，将**整个项目**上传，包括 `.github/workflows/pages.yml` 和 `public/data/`，不要只上传 HTML。
2. 默认分支使用 `main` 或 `master`；如果使用其他分支，请同步修改工作流中的 `branches`。
3. 仓库进入 **Settings → Pages → Build and deployment → Source**，选择 **GitHub Actions**。
4. 在 **Actions** 页运行 **Deploy WCA statistics to GitHub Pages → Run workflow**，之后每次推送到默认分支也会部署。勾选 `refresh_data` 可以先获取默认选手的最新成绩再发布；不勾选则直接发布仓库中的快照。
5. 部署成功后，从 Pages 设置页或工作流获取网站地址，一般是 `https://用户名.github.io/仓库名/`。

部署文件为 `.github/workflows/pages.yml`，发布目录是 `public/`。静态资源和初始数据均使用相对路径，兼容仓库子目录。网站无需服务器、API 密钥或 GitHub Token。

- **首次打开**：直接读取随网站发布的十五人真实成绩快照，不依赖现场连接 WCA。
- **新增 / 更新**：浏览器直接请求 WCA 公开 API（当前允许跨域 GET），仍需要访客能访问 WCA 官网。接口不可用时保留旧缓存。
- **公共默认数据**：编辑 `public/default-members.json`。每次打开都补齐默认名单，默认选手没有移除入口，也无法通过页面操作移除；旧版本已移除的默认选手会恢复。用户手动添加或导入的非默认选手仍可移除。新增默认成员不会清除已有手动成员。
- **个人操作不是全站管理**：网页上的添加、移除、更新只影响当前浏览器，不会修改 GitHub 仓库，也不会影响其他访客。
- **每日自动更新**：GitHub Actions 每天北京时间 08:00（UTC 00:00，`0 0 * * *`）自动获取默认名单所有选手的最新成绩，然后重新部署。获取失败时停止发布，保留线上旧版本。GitHub 定时任务可能延迟，并非精确定时；公开仓库连续 60 天没有活动时，GitHub 可能暂停定时工作流，需要到 Actions 重新启用。
- 定时更新和手动 `refresh_data` 只更新当次发布内容，不写回仓库；下次普通推送仍会使用仓库快照，如需同步最新成绩，可再手动勾选 `refresh_data` 发布。要持久更新仓库中的默认快照，运行 `npm run sync:defaults`，提交 `public/data/` 的变更。网页中的个人操作不会写回仓库。
- 本地 `localhost:5288` 的个人名单不会自动同步到 GitHub Pages，可用「备份名单 / 导入名单」迁移。

## 页面功能

- **选手 Ao 统计**：各项目的最佳 Ao5 / Ao12 / Ao25 / Ao50 / Ao100。
- **最佳 / 最近**：在下方窗口详情的「统计范围」中切换，概览表同步切换。「最近」是该项目最后 N 次正式尝试，不是最后一个有效 Ao。
- **组成详情**：点击概览表或排行榜中的 Ao 数字，查看该窗口所有单次、最快与最差的剔除项、起止比赛。展开来源表可查看每次成绩所属的比赛、轮次和尝试编号。
- **Ao 排行榜**：比较自行添加的选手，选择项目、Ao 长度与最佳 / 最近。有效平均并列时名次相同；DNF、次数不足或不适用会单独列出。
- **自行加人**：左侧输入 WCA ID 点击 `＋`，自动拉取成绩并计算；不限制选手的世界排名。
- **更新当前选手**：重新获取官方逐次成绩并计算 Ao。失败时保留旧缓存。
- **计算规则**：展示算法、数据处理和与原站的差异，不将非官方统计标为官方纪录。
- **备份 / 导入名单**：导出 JSON 名单；导入时合并成员并重新联网获取成绩。名单备份只包含 ID，不包含成绩缓存。

## 核心计算口径

实现依据：[参考项目 AverageOfX 源码](https://github.com/jonatanklosko/wca_statistics/blob/master/statistics/abstract/average_of_x.rb)。独立编写 JavaScript 实现，采用其连续窗口与双端 5% 去尾算法。

1. 一名选手、一个项目的正式尝试按顺序串起来，**可以跨轮次、跨比赛**。
2. 逐个移动长度为 N 的窗口，而不是选生涯最快 N 次，也不是把官方轮次 average 再平均。
3. 每端去掉 `ceil(N × 0.05)` 个成绩。
4. 对剩余成绩求算术平均，四舍五入到百分之一秒。最少步单次是整数步，平均保留两位小数。

| 类型 | 去最快 | 去最差 | 参与平均 |
| --- | ---: | ---: | ---: |
| Ao5 | 1 | 1 | 3 |
| Ao12 | 1 | 1 | 10 |
| Ao25 | 2 | 2 | 21 |
| Ao50 | 3 | 3 | 44 |
| Ao100 | 5 | 5 | 90 |

- `DNF (-1)` 与 `DNS (-2)` 保留在连续序列中，按无穷大排序。去尾后仍有无效成绩，该窗口就是 DNF。
- API 中 `0` 是未进行的尝试占位，跳过，不计为零秒或补成一次还原。
- 次数不足 N 不生成平均；已有足够次数但所有窗口都是 DNF 时，最佳显示 DNF。
- 历史最佳是所有有效窗口中四舍五入后最小的值；同值保留先出现的窗口。
- 相同值的单次按窗口内原始顺序打破去尾平局，确保两端剔除数量精确。
- 与参考项目一致，多盲和旧制多盲不计算 Ao。

### 顺序局限及与原站的差异

公开 API 没有每次还原的真实时间戳。本应用按**比赛开始日期 → 比赛 ID → 轮次 → 尝试序号**排序。缺日期的比赛排在后面并在窗口详情提示。

参考项目 SQL 是 `competition.start_date, round_type.rank, attempt_number`，没有明确同日不同比赛的完整平局规则。本应用额外用比赛 ID 固定同日比赛顺序，避免交错同场成绩。因此同日不同比赛、跨日比赛的顺序不保证与真实时间或原站一致。普通不同日期比赛按相同的连续单次与去尾规则计算。

原站出于性能只考虑各项目单次世界前 500 的人，并展示前 10。本应用不做这一筛选，只计算用户添加的名单，**不是全球排行榜**。不同快照日期也会导致结果不同。

## 数据与保存

- 数据来源：WCA 公开 API 的选手档案、逐轮 attempts 与比赛日期。
- `public/data/{WCA_ID}.json` 是十五位默认成员的真实初始快照，`fetchedAt` 为获取时间；不使用虚构成绩。加载时比较内置快照与浏览器缓存的时间，使用较新的一份。
- 成员与更新后的逐次成绩保存在当前浏览器 `localStorage`，沿用旧版存储键。最多 100 人。清理网站数据会删除浏览器缓存，请提前备份名单。
- Ao 在浏览器中计算并按数据对象缓存；更新某人后重新计算。没有请求任何第三方统计服务。
- 内置快照、已存浏览器缓存可在本地服务器开启时离线计算；添加、更新需要访问 WCA 官网。
- 本地 Node 服务提供同源代理，普通请求缓存六小时，手动刷新最少间隔一分钟，最多同时获取三位选手。GitHub Pages 不使用此服务，改为浏览器直连公开 WCA API。
- 本地服务优先使用系统 curl，在 curl 不可用时使用 Node fetch；连接失败请检查网络或代理。不提供登录或云端同步。

更新所有默认成员的初始快照（不是浏览器缓存）：

```sh
npm run sync:defaults
```

只更新蔡扬仍可使用 `node scripts/sync-owner.mjs`。获取失败会保留原快照并报告失败成员。

覆盖前会将旧快照备份到当前用户目录下 `.pi/agent/backups/wca-statistics`。当前电脑即 `C:\Users\HP\.pi\agent\backups\wca-statistics`。

## 文件结构

```text
server.mjs                  本地服务器与 WCA API 代理，默认 5288
lib/wca.mjs                 获取和整理公开 WCA 数据
public/app.js               成员、缓存、交互、路由
public/averages.js          连续尝试、Ao 滑动窗口、去尾、Ao 排行榜
public/average-views.js     概览、完整窗口详情、排行榜、规则页面
public/averages.css         Ao 界面样式
public/stats.js             项目、成绩格式与结果排序等基础函数
public/default-members.json 默认成员名单与迁移版本
public/wca-data.js          浏览器直连 API、统一数据格式与名单迁移
public/data/*.json          十五位默认成员的真实初始快照
scripts/sync-defaults.mjs   更新全部默认快照，覆盖前备份
scripts/sync-owner.mjs      仅更新蔡扬快照
.github/workflows/pages.yml GitHub Pages 发布配置
启动WCA统计.bat             Windows 启动入口
```

运行核心验证：`npm test`。Ao 测试包括去尾数量、DNF/DNS、占位 0、FMC、跨轮次窗口、并列、精确剔除、次数不足，以及用逐窗口排序参考算法核对增量算法与真实快照。

## 项目关系

灵感与算法参考自 [jonatanklosko/wca_statistics](https://github.com/jonatanklosko/wca_statistics)，不是其全部全球统计的移植。本版本重点实现用户名单内的连续平均，不需要 Ruby、MySQL 或下载全量数据库。没有复制原仓库代码。

非 WCA 官方产品，与 WCA 无隶属关系。
